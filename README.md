# Gosleeper Agent Skills

个人 Agent Skills 仓库。

## Skills

- `github-cli`：使用 GitHub CLI 搜索和管理 GitHub。
- `daily-log`：把当前上下文里"今天做的"事按固定格式追加到当天日志，汇总成一份可复盘的日志。

## 安装

```powershell
npx skills add gosleeper/agent-skills --skill github-cli --agent codex --global
npx skills add gosleeper/agent-skills --skill daily-log --agent codex --global
```
